## Printf Implementation

All code written in C by Tahn Rainbird and Carmelita Hatfield.

# Usage

This Repo is an implementation of the standard library C function printf.

This implementation supports the identifiers %s, %c, %i, %d, %x, %X, %b, %u, %o

This implementation intends to handle inputs in the same manner that the regular
printf function does in the case of NULL inputs, undefined identifiers, etc.

# Error Handling

All errors will exit with exit code 98.
